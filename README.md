# 🔥 Conversor de Temperatura em C#

Este é um programa simples feito em C# que converte temperaturas de Fahrenheit para Celsius usando entrada do usuário via console.

## 📌 Objetivo

Demonstrar os princípios básicos de programação em C#, incluindo:

- Entrada e saída de dados
- Conversão de tipos
- Operações matemáticas
- Estrutura sequencial de execução
- Formatação de saída

## 🧮 Fórmula usada

A fórmula para conversão é:

Celsius = (Fahrenheit - 32) × 5 / 9



## 🚀 Como executar

1. Abra o terminal ou prompt de comando.
2. Compile o programa:

Comando: "dotnet run"

## Arquivo principal ##:
ProgramConversor.cs: contém todo o código-fonte do programa.

# 🛠️ Requisitos #
.NET SDK instalado (qualquer versão compatível com C# 8+)

# 📚 Aprendizados #
Este projeto ensina:

Como trabalhar com entrada do usuário usando Console.ReadLine()

Como converter string para double

Como fazer cálculos matemáticos em C#

Como exibir texto formatado com Console.WriteLine()
